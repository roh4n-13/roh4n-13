## 🚀 Featured Project

### ✅ [Task Tracker Pro](https://github.com/roh4n-13/muse-taskapp)

A production-grade Android task manager: 21-field tasks, exact-time reminders with in-notification **Done**, call/WhatsApp actions, cost (*Kharcha*) tracking with vendor-wise dues, and optional two-way **Google Sheets sync** — all fully functional offline.
